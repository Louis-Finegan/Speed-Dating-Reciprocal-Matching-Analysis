# Project explanations

Project explanations are saved here as Markdown files. Equations use `$...$` for inline math and `$$...$$` for display math.

- [Network structure](network_structure.md): nodes, edges, directional attraction and recommendation subnetworks.
- [Theoretical setup](theoretical_setup.md): mathematical definitions, assumptions, algorithms and evaluation metrics.
- [Results discussion](results_discussion.md): interpretation of the saved preliminary results and their limitations.
- [Figures](figures.md): generation commands and interpretation of regression and network plots.
- [Participant counts](participant_counts.md): the displayed event versus the full dataset.
- [Reading the regression figure](reading_the_regression_figure.md): how to interpret each panel and its limitations.
- [Mutual-interest figure](mutual_interest_figure.md): reciprocal probability curves and held-out mutual calibration.

Results discussions describe the output available when written; they are not automatically regenerated when experiments are rerun.
